# 知序 Zhixu

**让生活更有序。** Windows 本地记录软件：图文日志、每日待办、照片与视频相册，在一个地方保存。

无需账号、无需联网、不使用 WPS 小助手，数据保存在你的电脑中。

**当前稳定版：1.45.0。** 请从下方“最新版本下载”获取 Windows 程序。GitHub 文件列表右侧的 1.3、1.35 等文字，是各文件最后一次修改的历史提交说明，不代表当前安装版本；历史功能变更集中在 CHANGELOG。

## 下载与使用

1. 打开 [最新版本下载](https://github.com/MnVZr/zhixu/releases/latest)。
2. 在 **Assets** 下载 `Zhixu-1.45.0-Windows-x64.zip`。`Source code` 是源码，普通用户不需要下载。
3. 完整解压到可写入的文件夹，双击 **知序.exe**，无需安装 Python。

支持 Windows 10/11 64 位，推荐系统自带的 Microsoft Edge。知序以独立应用窗口打开，缺少 Edge 时使用默认浏览器。请不要直接在压缩包中运行。

## 主要功能

- **日志**：一天多篇、纵向阅读、编辑与折叠；粗体、斜体、列表、小标题、自动保存。
- **图文混排**：工具栏、拖拽或粘贴插入图片和 MP4，添加图注、关联相册；其他文件显示下载链接。
- **番茄钟**：右下角闹钟入口，专注/休息时长、轮数、暂停和系统通知；可与待办时段联动。
- **待办**：时段、提醒、优先级、颜色类别和可选的零点顺延。
- **相册**：分类、搜索、按时间/大小/名称排序；预览缩放、隐藏图注、重命名和来源日志跳转。
- **设置**：主题色、字号、待办排序、默认优先级和统计栏。
- **数据**：自选本地存储位置、迁移、读取旧目录、备份导入、日志文本与相册导出。

## 开始记录

选择日期，点击“新建日志”。停止输入约 0.6 秒自动保存，`Ctrl+S` 立即保存；看到“已保存”后关闭。

正文中点击图片可加入相册或编辑图注，双击查看大图与完整信息；日志上方可切换图注显示。预览顶部显示导入日期、大小和来源日期；点击左上角名称重命名，后缀自动保留。左右半透明箭头翻页，滚轮缩放、拖动平移，右下角鸟瞰图定位。

点击“＋ 图注”，再点图片上的位置，即可添加图注；每张图片支持多条。点击图注打开悬浮编辑窗，调整文字、文字色、底色、字号和透明度，自动保存；拖动图注改变位置，缩放时文字和背景等比例变化。眼睛图标隐藏或显示全部图注。顶部可“查看对应日志”或将当前照片“设为封面”。图注不会修改原图；相册导出保留原文件及图注信息。

统计栏显示当日日志篇数。在设置中开启“显示心情／显示天气”，点击统计栏对应图标手动记录，按日期保存，可留空。

待办背景色：蓝灰=低，浅绿=普通，浅橙=高，浅红=紧急。悬停查看说明，点击内容编辑。

点击悬浮闹钟进入番茄钟；拖动顶部手柄调整位置（也支持手柄方向键），位置自动记住，双击手柄恢复默认位置。组件会尝试避开操作按钮，打开弹窗时隐藏。设置后点击“开始专注”。一轮为专注加休息，可设置多轮；时长配置对下次开始生效。新建/编辑待办时，勾选时段后可开启自动番茄钟，和普通待办提醒分别控制。时段截止、待办完成或关闭联动会结束关联计时；同一时段只自动启动一次。遇到已有计时不会打断，会通知该待办未启动。暂停与计时状态保存在本地，重启恢复；退出程序期间不通知，重启时若专注已逾期会开始休息，已过待办时段不会继续。

提醒需要程序或后台运行；关机、休眠和 Windows 勿扰可能影响通知。顺延默认关闭，开启后下一零点生效，关机期间遗漏的顺延下次启动补齐。退出后台停止提醒，不设置开机自启。

## 更新与数据保护

**程序与数据分开管理。发布包不含任何个人日志、照片或数据库。**

- 新用户默认使用 `%LOCALAPPDATA%\Zhixu\data`。
- 旧版本旁的 `data` 会继续使用。自选路径记录在 `%LOCALAPPDATA%\Zhixu\storage.json`，更换新版 EXE 后仍读取该目录。
- 数据结构升级前在数据目录的 `upgrade-backups` 中自动保存数据库快照，原始媒体保留在 `attachments` 中。
- 自选目录不可访问时会提示错误，不会悄悄创建空库。

推荐更新步骤：

1. 旧版导出完整备份，在设置中“退出知序与后台”。
2. 新版解压到新文件夹，或仅替换程序文件，**不要删除或覆盖原 `data` 文件夹**。
3. 若未自动读取：设置 → 数据与导出 → 选择旧版完整 `data` 文件夹 →“读取已有数据”；也可“恢复备份”。

“复制并切换”将当前库复制到空目录并切换，保留原目录；“读取已有数据”读取所选库，不合并两份数据。“恢复备份”支持 Demo 至 1.4 及当前版本的完整备份 ZIP，恢复到新目录，不覆盖当前库。

日志文本导出用于阅读；相册导出包含原媒体与图注/来源信息 JSON；**完整备份**可恢复日志、待办、设置、相册与全部附件。重要资料另存一份完整备份到其他磁盘。数据库快照不含媒体，不能代替完整备份。

详见 [数据迁移与恢复](docs/DATA.md)。

## 从源码运行与构建

需要 Windows、Python 3.14 和 Git。日常运行不需要 Node.js。

```powershell
git clone https://github.com/MnVZr/zhixu.git
cd zhixu
python -m pip install -r requirements-build.txt
python app.py
```

构建：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

输出 `release\知序.exe` 和 `Zhixu-1.45.0-Windows-x64.zip`。构建只包含程序、文档和许可证。`ZHIXU_DATA` 环境变量可指定隔离开发数据目录。

测试：

```powershell
python -m unittest discover -s tests -v
# 离线界面测试需 Node.js 22+：
npm install
npm test
```
