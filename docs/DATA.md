# 数据迁移与恢复

`journal.db` 保存日志、待办、相册、设置和图注；`attachments/` 保存原媒体与文件；`upgrade-backups/` 保存升级或切换前的数据库快照。

请完整保留数据库与附件目录，不要改动内部附件文件名。快照不包含媒体，重要资料另做完整备份。

## 迁移和切换

设置支持任意可写入的本地绝对路径，也可点击“选择位置”。迁移目标必须为空，且不能与当前目录互相包含。复制校验成功才切换，原目录不删除；失败可能保留未完成的目标目录，检查后自行清理。

打开旧目录先校验数据库与附件完整性，再自动升级。另一知序进程占用的目录不能同时打开。不要在运行中用同步软件覆盖数据库，退出后再同步完整目录。

导入 ZIP 会在新目录恢复再切换，不覆盖当前目录。目前不支持两个资料库自动合并。只导入自己信任的备份。

## 旧版兼容

Demo 至 1.35 日期日志迁移为当天第一篇，保留标题和正文。旧图片/视频作为正文图文展示，普通附件为下载链接；相册关系保留。

当前结构版本为 6。旧版程序不适合继续写入已升级库。若需回退，先退出程序，使用升级前数据库快照和对应原附件目录。

## 恢复方式

1. 完整备份 ZIP：设置 → 恢复备份。
2. 完整旧目录：设置 → 选择包含 `journal.db` 与 `attachments` 的目录 → 读取已有数据。
3. 自选磁盘不可用：连接相应磁盘后重启。确需手动修改路径时，退出程序，备份 `%LOCALAPPDATA%\Zhixu\storage.json`，再将 `data_path` 指向完整有效目录。

日志文本和相册导出用于阅读/整理，不包含全部应用状态，不能替代完整备份。

1.4 的番茄钟配置/状态、待办联动标记、图注位置/样式均保存在数据库中，完整备份可恢复。相册导出中的 JSON 包含图注样式，导出原图不烧录图注。

1.45 保留原图注并迁移为多图注；图注位置和样式、相册封面、番茄钟位置、每日心情天气均包含在完整备份中。相册导出包含原始文件与多图注 JSON，未将图注烘焙到图片。

1.5 删除日志后移入数据库内的删除记录，可在当前会话撤销；原媒体文件与相册成员关系保留。完整备份包含删除记录。安装程序只写入程序和文档，既有 data 目录和外部资料位置不变。
